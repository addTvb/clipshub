# Clipshub Landings

Standalone Next.js app with two public landing pages:

- `/en/clipper` — for creators
- `/en/business` — for brands

No backend required — API calls go to local mock routes under `/api/mock`.

## Local

```bash
npm install
npm run dev
```

Open:

- http://localhost:3000/en/clipper
- http://localhost:3000/en/business

## Deploy (Vercel)

```bash
npx vercel --prod
```
